**Deviations**
1. The `~` prefix: the orchestrator note said "the whole path starts with `~`"; the ticket body says the run is "immediately preceded by … `~`". Implemented the stricter reading (`["~"]` exactly before the run) — the looser one would reclassify the very `~/Projects/<repo>/.agents/skills/<x>` case the ticket says to leave alone. Both agree on `~/.claude/skills/foo`.
2. Rule (ii) drops the leaf-link requirement entirely (canonical containment) — so a `local` row whose `source_ref` is a real directory *inside* central (no link at all) is reclassified too. Correct by the same argument (its "source" is the central copy) but worth knowing.
3. Whole `ensure_schema` is one transaction, not only the incremental branch; `MIGRATION_V4` lost `BEGIN`/`COMMIT` (see above). Column-presence guard applied to the **V9** step only — older `ALTER` steps stay as they were (any DB that reaches them either never wrote `user_version` at all pre-ticket-06 and is now atomic, or is fresh).
4. Traversing subpath is refused **plain** (`OTHER` on the wire), not typed — a `..` subpath has no legitimate origin (URL the operator pasted / a record the app wrote), so it is the ADR-0001 safety valve rather than an operator condition. `LinkChain` backslash refusal is typed (`SymlinkEscapesRepo`) as the ticket asks.
5. Detach guard is **typed** via the pre-existing `CentralPathMissing` rather than plain or a new code; DTO bit is `detachable: bool` (an affordance mirroring `refreshable`, backed by one core rule `is_detachable`) rather than `central_present: bool` — so the card cannot re-derive the rule and core's refusal and the DTO's answer are the same function by construction.
6. `describeCommandError` is also imported by two **test** files (`useAddSkillFlow.test.ts` uses it as the reporter double's real formatter; `useStatusReporter.test.ts` by name only) — pre-existing, test-only; runtime importers are now the reporter alone.
7. `useSyncOrchestration.ts:86` keeps its own ``t(`tools.${key}`, { defaultValue: info.label })`` — its fallback is the **backend** label, not the key, so it is a different rule and was left alone.
