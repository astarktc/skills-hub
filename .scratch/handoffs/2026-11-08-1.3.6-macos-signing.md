## Learned

- **Tauri's DMG-only pass deletes the `.app` it built.** Verify the shipped artifacts (the updater tarball and the DMG),
  never `bundle/macos/*.app`.
- **A local build linked Homebrew's `libgit2` via pkg-config,** which the hardened runtime would refuse. `git2` now uses
  `vendored-libgit2`, and the release checks that the app links only system libraries.
- **Pushing a tag yourself triggers `release.yml`'s `push: tags`** as well as any dispatch. The concurrency group
  cancels one of the two, so don't dispatch after a manual tag push.
- **A launch proof that never touches the operator's library:** run `HOME=$(mktemp -d) "<app>/Contents/MacOS/app"`.
  The app builds its DB and central repo under the throwaway home, and the Keychain is unreachable there, so no
  token prompt appears.
