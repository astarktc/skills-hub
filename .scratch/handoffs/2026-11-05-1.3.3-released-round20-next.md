## Learned this session

- **A worktree child has no `.pi/` skills** (gitignored), so e.g. `impeccable` was unavailable to L4. Brief UI copy
  work accordingly.
- **`gh pr checks` on a draft PR is the only way to compile Windows-only Rust** from this Mac. Cfg-gated test helpers
  can pass macOS clippy and still fail Windows clippy as dead code.
- **`synchronous = FULL` under WAL needs a longer busy timeout** on hosted Windows runners (30 s, `b8a530b`).
- **A typed `SignalError` attached with `anyhow::Context` is invisible to `err.chain()` downcasts.** Use
  `err.downcast_ref::<SignalError>()`, as `CommandError::from_anyhow` does.
- **After a `git cherry-pick` that prints an "empty commit" hint, verify the tree** before deleting the source branch.
- **Removal-safety reviews converge slowly.** Each adversarial round found a narrower class: aliases → case → cache →
  library boundary → mounts → mount-table parsing. Budget several rounds for anything touching `removal_fence.rs`.
