## Learned this session

- **A false-positive ChatGPT "Subscription Sharing usage limit" error** can stop an OpenAI child even with quota left.
  Ask the operator to clear it (ChatGPT → Settings → Usage → App limits → toggle the app, set 100%, Save) rather than
  treating the account as exhausted.
- **Parallel lanes appending to the same registry lists merge mechanically** if each appends one marked block per list.
  Replay a lane's own diff onto `main` rather than resolving conflict hunks by hand. The README table test requires
  adapter rows before the reader-only rows.
- **Removal-safety work converged on one principle** after five rounds: delete only what is provably a duplicate, at
  the moment of deletion, and only inside the folder you own. Give round 3+ reviewers that principle, not a list of
  patches.
- **Two independent reviewers in parallel** (Astra and Sol) on a hard round found different, complementary classes of
  finding.
