## Learned

- Parallel row lanes merge cleanly when each appends one marked block per list. Replaying a lane's own diff onto
  `main`, instead of resolving conflict hunks, keeps it mechanical. The README test requires adapter rows before the
  reader-only rows.
- Removal-safety work took five review rounds again. The round that converged had one governing principle: delete
  only what is provably a duplicate, at the moment of deletion, and only inside the old Library folder.
- **"The ChatGPT user has reached their Subscription Sharing usage limit" can be a false positive**, a known sync bug
  for third-party harnesses such as Pi that log in through ChatGPT. The account may still have quota (the operator had
  37% left, 2026-11-06). Don't treat it as exhausted. Ask the operator, who can clear it: ChatGPT → Settings → Usage →
  App limits → toggle the app on, set it to 100% and Save. Then tell the child to continue.
